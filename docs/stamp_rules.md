# スタンプ制作の決まりごと(set01 の指摘から)

set01「ていねいインコ」で、ユーザーと品質チェックから受けた指摘を全部まとめたもの。
**同じ指摘を二度と受けないための決まり。** デザイン・アニメ化・品質チェックの全員が、作る前と見せる前に必ず読む。
新しい指摘を受けたら、ここに書き足す。

---

## 1. 腕(羽)

| # | 決まり | set01 で受けた指摘 |
|---|---|---|
| 1-1 | 羽は**肩(付け根)を支点にして回す**。羽の中心で回さない。付け根は動きの間ずっと同じ位置に置く | 「腕の軸がおかしい」 |
| 1-2 | 付け根は**体の輪郭より4px以上内側**に重ねる。どのコマでも羽が体から離れて浮かない | 「羽が宙に浮いている」(03・07) |
| 1-3 | 敬礼: 付け根は体の右肩、**ギザギザの羽先がおでこ**(右目の右上、顔の内側)。`inko.SAL`(140°)を使う。羽先と付け根を逆にしない。頭の輪郭に沿わせない(耳に見える) | 「葉っぱ/垂れ耳/ロップイヤーに見える」「軸がおかしい」 |
| 1-4 | **左右の羽を両方動かす**。角度もタイミングも左右で変える。左右同じ動きは禁止 | 「右手が動いていない」「左右同じは作り方が弱すぎる」 |
| 1-5 | ポーズを保つ腕(敬礼している腕など)も止めきらず、±2〜3°だけ揺らす | 同上 |
| 1-6 | 振れ幅は**最大16°くらい**まで。大きく振らない | 「全体的に腕を動かし過ぎ」 |
| 1-7 | 小物(マフラー・帽子・鏡餅など)を持つ・着けるときも 1-1〜1-6 を守る。小物は羽と一緒に付け根を支点に動かす | (set02 から予防) |

## 5. 絵柄

- 輪郭は固くしない。ゆるく、ふわふわに(set01 v2 の `tools/soft.py` の描き方を使う)。「淵が固い」と指摘された。

## 6. ファイルの規定

- スタンプ: 320×270・12コマ・2秒×2回。容量は300KB以下で、作り直しに備えて**280KB以下**をめざす。
- メイン画像: 240×240 の**アニメ(APNG)**。セットの中のスタンプと同じ動き。300KB以下。
- タブ画像: 96×74。**キャラだけを入れる**。セリフの切れ端を入れない。

- お正月(あけおめスタンプ)のセットは、メイン画像に LINE の専用フレーム(`assets/frames/`、毎年配られるもの)を付ける。スタンプは 194×194 以内に縮めて、フレームの内側から上下左右10pxずつあけて置く。フレームの色・形は変えず、はみ出さない・被せない。メイン画像以外には使わない(set03 でフレームなしでリジェクトされた)。
- お正月のセットは、パッケージの8個以上を年末年始のあいさつにする。
