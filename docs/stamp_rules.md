# スタンプ制作の決まりごと(set01 の指摘から)

set01「ていねいインコ」で、ユーザーと品質チェックから受けた指摘を全部まとめたもの。
**同じ指摘を二度と受けないための決まり。** デザイン・アニメ化・品質チェックの全員が、作る前と見せる前に必ず読む。
新しい指摘を受けたら、ここに書き足す。

---

## 1. 腕(羽)

| # | 決まり | set01 で受けた指摘 |
|---|---|---|
| 1-1 | 羽は**肩(付け根)を支点にして回す**。羽の中心で回さない。付け根は動きの間ずっと同じ位置に置く | 「腕の軸がおかしい」 |
| 1-2 | 付け根は**体の輪郭より4px以上内側**に重ねる。どのコマでも羽が体から離れて浮かない | 「羽が宙に浮いている」(03・07) |
| 1-3 | 敬礼: 付け根は体の右肩、**ギザギザの羽先がおでこ**(右目の右上、顔の内側)。`inko.SAL`(140°)を使う。羽先と付け根を逆にしない。頭の輪郭に沿わせない(耳に見える) | 「葉っぱ/垂れ耳/ロップイヤーに見える」「軸がおかしい」 |
| 1-4 | **左右の羽を両方動かす**。角度もタイミングも左右で変える。左右同じ動きは禁止 | 「右手が動いていない」「左右同じは作り方が弱すぎる」 |
| 1-5 | ポーズを保つ腕(敬礼している腕など)も止めきらず、±2〜3°だけ揺らす | 同上 |
| 1-6 | 振れ幅は**最大16°くらい**まで。大きく振らない | 「全体的に腕を動かし過ぎ」 |
| 1-7 | 小物(マフラー・帽子・鏡餅など)を持つ・着けるときも 1-1〜1-6 を守る。小物は羽と一緒に付け根を支点に動かす | (set02 から予防) |
| 1-8 | 羽の形はふわふわ。輪郭をボコボコにしない | 「腕がボコボコしてる」 |

## 2. 顔

| # | 決まり | set01 で受けた指摘 |
|---|---|---|
| 2-1 | 目・ほっぺ・くちばしは**頭と一緒に動かす**(おじぎ・ジャンプ・傾きの全コマ)。目はくちばしの位置からのずれで置く(`inko.eyes`) | 「目が追従してない」(02) |
| 2-2 | 目は大きめ。にっこり目・閉じ目は両端を丸く。「><」も丸い線で描く。角を作らない | 「目に角がある」「目をもっと大きく」 |
| 2-3 | 1つのスタンプの中で表情を変えない。途中のコマで普通の顔に戻さない。寝顔は一度も目を開けない | 「コマ2だけ普通の顔」「おやすみで目が開く」 |
| 2-4 | 口パク: くちばしの大きさと位置はそのまま。開くときは**形を少し丸くして色を #F0788A に変えるだけ**。部品を重ねない。くちばしの外にはみ出さない | 「口がグチャグチャ」「口がはみ出ている」 |
| 2-5 | セリフが出ている間は**全スタンプで口パク**する。1コマ目(完成形)は口を閉じる | 「全部口パクさせて」 |

## 3.5 動物キャラ(ひつじなど)

| # | 決まり | 受けた指摘 |
|---|---|---|
| 3.5-1 | 輪郭の線は太め(soften 後の約1.8倍、最低2.6)。細い線だと形がぼやける | set03「各輪郭の線を太くして」 |
| 3.5-2 | 前足ははっきり動かす: 付け根を支点に最大16°回しながら、最大5px持ち上げる(左右で交互・別の角度)。後ろ足も最大3px持ち上げる。インコの足の「少しだけ」(3-1)より大きくてよい | set03「手足をもう少し動かして。前足は何も動いていない」 |
| 3.5-3 | 耳は外側(濃い色)と内側(淡い桃色)の2色にして、付け根を顔の後ろに隠し、立体に見せる。耳も付け根を支点に左右別々に動かす | set03「耳と分かりづらいから立体感を」「耳も動かす」 |
| 3.5-4 | 鼻とほっぺの色は分ける(鼻はこげ茶、ほっぺはピンク) | set03「鼻とほっぺたの色を分ける」 |
| 3.5-5 | 角などの目印は大きく、頭にしっかり付ける(前髪の下から生やす)。体から離して浮かせない | set03「角を大きくして」 |
| 3.5-11 | 角のうず巻きの内側は角ではなく体。体の毛と同じ白で埋める(角の色・濃い色・透明にしない) | set03「角の内側は身体です。背景では無い」 |
| 3.5-6 | ひつじの角は、こめかみ(前髪の両わき)から生やし、外へ張り出してから下へ回り、先が顔の側(内側)へ巻き込む向きにする。左右は鏡うつし。耳は角の下から横に出す。向きは何通りか描き比べてから決める | set03「角の位置がおかしくない?」「内側に回るようにして」 |
| 3.5-9 | 顔まわりの部品(前髪・角・耳・顔)は、すべて同じ基準(顔のずれ)で動かす。基準がちがうと、おじぎやジャンプで前髪だけずれる | set03「頭のもこもこが動いた時に連動していない」 |
| 3.5-10 | もこもこの部品は、ふちをぐるりと全部もこもこにする。下や横を直線で切らない。波形(scallop)は小さいと谷がとがって「とげとげ」になるので、丸を輪に並べて重ねる描き方にする(内側の線は少し小さい白い丸で消す)。拡大して、とがった所がないか確かめる | set03「頭のモコモコの下部が直線」「とげとげしてる」 |
| 3.5-8 | 左右で対になる部品(角・耳など)は、片方を鏡うつしにした形と角度で作る。同じ形を回しただけで済ませない。手描きの揺れで形がずれないよう、座標を大きくしたパスを使う | set03「左の角と右の角度、形が違う」 |
| 3.5-7 | 顔の輪郭は体より太い線にする(顔が毛に埋もれないように)。目は小さくしすぎない | set03「顔の輪郭をもう少し太く」「目を少し大きく」 |

## 4.5 年賀状・手書きの演出

| # | 決まり | 受けた指摘 |
|---|---|---|
| 4.5-1 | 筆やペンで書く場面は、筆先を上から下へ動かすだけにしない。左右に振れながら進ませて、字を書いているように見せる | set03「左右に動かしながら書いているように」 |
| 4.5-2 | 干支などの動物キャラは、インコの形(卵形の体・羽・頭の毛・大きな目)を使わずに、その動物の形で描く。ひつじなら「横に広い雲のような毛の体」「はだ色の顔とおでこの毛の前髪」「横にたれた耳」「くるんとした角」「短い4本の足」「小さな目・鼻・ω の口」。動き(肩が支点・左右別々など)の仕組みだけ流用する | set03「羊っぽく見えない」「インコに見える」(2回) |
| 4.5-3 | はがき(年賀状)は角を丸くしない。四角い紙にして、はがきらしく見せる | set03「角は丸くしないではがき感を」 |
| 4.5-4 | 見せる前に、50%に縮めて「何も知らない人がその動物・その物に見えるか」を確かめる。元のキャラ(インコ)に見えたら見せない | set03 |

## 5. 絵柄

- 輪郭は固くしない。ゆるく、ふわふわに(set01 v2 の `tools/soft.py` の描き方を使う)。「淵が固い」と指摘された。

## 6. ファイルの規定

- スタンプ: 320×270・12コマ・2秒×2回。容量は300KB以下で、作り直しに備えて**280KB以下**をめざす。
- メイン画像: 240×240 の**アニメ(APNG)**。セットの中のスタンプと同じ動き。300KB以下。
- タブ画像: 96×74。**キャラだけを入れる**。セリフの切れ端を入れない。

## 6.5 申請文

| # | 決まり | 受けた指摘 |
|---|---|---|
| 6.5-1 | 説明文は**全角を2文字と数えて160文字以内**にする(LINE の登録画面がこの数え方)。タイトルも全角2文字で40文字以内。本命の文をこの数え方で作り、「長い版・短い版」を作らない | set02「255/160 で入らない」 |
| 6.5-2 | 英語のタイトルは1文字ずつ数え、先頭と最後の文字まで確かめる。貼った後に登録画面の文字数が合っているかも見てもらう | set02「英語のタイトルも気を付けて」(先頭の P が抜けていた疑い) |
| 6.5-3 | 文字数は Python で数えて、数え方といっしょに書く | — |

## 7. ユーザーに見せる前の確認(必ずやる)

1. スタンプごとに12コマを並べた一覧画像を作り、Read で全コマを見る。
2. 1〜5章の表を1行ずつ、全スタンプ・全コマで確かめる。特に次の5つ:
   - 羽の付け根が体に重なっていて、肩を支点に回っているか
   - 左右の羽が別々に動いているか
   - 目が頭と一緒に動いているか
   - 表情が途中で変わっていないか
   - 口がはみ出していないか
3. 50%に縮小して(スマホでの見え方)、敬礼などのポーズが何も聞かされていない人にも分かるか確かめる。
4. どれか1つでも外れていたら直してから見せる。確認した結果は `qa.md` に書く。
