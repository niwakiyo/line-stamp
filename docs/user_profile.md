# このユーザーと、作りたい作品(これまでのやり取りから)

作業の前に必ず読む。`docs/stamp_rules.md` は「やってはいけないこと」、ここは「何を目指しているか」。

## どんな人か
- 自分で LINE スタンプを販売している作り手。1セット目は申請が通って販売中。売れることを目標にしている
- 完成品を細かく見る。1コマずつ、部品の位置・線・色・動きの不自然さまで気づく
- 同じ指摘を何度もさせられること、使用量(データ)を無駄にされることを強くいやがる
- 「言われたことだけ直す」のではなく、言われていない所も自分で考えて良くしてほしいと思っている
- 説明は短く、日本語で。英語や専門用語は使わない

## 作りたい作品
- **こだわりと工夫が見える絵。** 「丸を2つ置いただけ」「直線」「単色」「使い回し」は手抜きに見える。小物ひとつにも、形・色・光・動きの工夫を入れる
- **季節感がひと目で伝わる。** キャラの装い、背景の物、文字の色まで季節にそろえる
- **にぎやかで華やか、でもやりすぎない。** 飾りは多めに、ただし目や文字をじゃましない
- **動きに躍動感。** キャラは一か所で揺れるだけにしない。移動・ジャンプ・大きな腕の動き・遅れてゆれる物。背景の物(そり・ベル・電球)も動く。動きは最後まで続き、途中で何もなくならない
- **1枚の絵としてまとまった構図。** すみに分けて置かない。大きな物を重ね、文字も絵の一部にする
- **文字は手書き風で、まっすぐ並べない。** カーブ・段差・大きさ・色の変化
- **サムネイル(メイン画像)で、どんなスタンプか分かる。** 文字入り・華やか
- **キャラはその動物・人らしく。** 元のキャラ(インコ)の形を残さない。人気の作品と比べて見劣りしないこと

## 作るときの心がけ
- 何か足すとき、まず「人気の作品ならどう描くか」を考え、最低3つの工夫を入れる(例: 眼鏡なら、形・ふちの太さ・レンズの光・つる・動きの中のキラリ)
- 見せる前に、ユーザーになったつもりで全コマを拡大して見て、指摘されそうな所をすべて直す
- 「消える」「止まる」「さびしい」所がないか、最後のコマまで確かめる

## お手本(合格をもらったセット)
- **set04 クリスマス(`work/set04/`、作り方は `tools/xmas.py`・`tools/xmas2.py`)が「良くできている。こんな感じで次から作成して」と言われた基準。** 次のセットはこの水準・作り方で作る。
  - キャラ: 大きく動く(移動・ジャンプ・両手を頭の上まで)。持ち物は手について行く。横向きが必要な場面(そりを引くなど)は横向きの絵を描く
  - 構図: 大きな季節の物(リース・ツリー・ガーランド・暖炉など)をキャラの後ろ・前に重ねて1枚の絵に。4つに区切らない。小窓を作らない
  - 飾り: 大きさ・色・柄を1つずつ変え、季節らしい細部(ふわふわの口・のぞくプレゼントなど)を足す。点滅はおだやかに(チカチカさせない)。大きな飾りは小さく現れてだんだん大きくなるなどの動き
  - 文字: 丸い手書きの書体(筆の書体は使わない)、1文字ずつ季節の3色、カーブ・段差。お祝いのスタンプは全体にキラキラ
  - 作りにくい場面は、色・柄・形がそれぞれちがう、ずっと動き続ける手書きのカード(20コマ)にする
  - 仕上げ: 全コマをシートで見る → ふち10pxを機械で確認 → 透過後の文字の抜けを元のシートと比べて確認 → 50%に縮めて確認

## お手本2: セリフとテロップ(set05 で「すごくいい。学習して」と言われた)
- **set05「サンタとトナカイの本音」(`work/set05/`、作り方は `tools/set05.py`・`tools/textfx.py`)が、セリフ・テロップの見せ方の合格基準。** 次からのセットも、セリフはこの水準で作る。
- セリフの中身: かわいい絵と、ぶっちゃけた本音・仕事や生活の「あるある」のギャップ。口語のまま(「俺、」「〜わ」「〜じゃね?」)、ツッコミ・気づき・ため息など感情の流れがあるもの。
- 1つのセリフに1つの「舞台」を用意する。内容に合う身近な物を枠にする:
  - テレビのテロップ・豆知識、お知らせ看板、カーナビ画面、ホワイトボード、スマホのメッセージ、検索バー、日めくりカレンダー、求人ポスター、不在通知票、駅の案内板、はんこ、名札・数え札
  - 気持ちを表す吹き出し: 叫び(ギザギザ)、怒りの爆発、考え雲、ひそひそ(点線)、湯気のもわもわ
- 文字の出し方はセリフの気持ちに合わせる(次々出すだけにしない):
  - 打ちこむ(カーソル)・ペンで書く・マーカーで書いて赤丸 / すべりこむ・流れてくる / 上から落ちてゆれる / ズームで飛びこむ+集中線 / ぼやけてからはっきり / 1字ずつ大きく伸びる(叫び)/ はんこをドンと押す
  - 段階のあるセリフは「間」を作る(とまどい → びっくり → オチ)。オチの字は大きく、色を変え、遅れて出す
  - 出たあとも何かが動き続ける(▶▶が流れる、数字が回る、におい線、汗、ぴょんぴょん)
- 書体はセリフの性格ごとに変える(太いゴシック=怒り・テロップ、ドット=画面、手書き=つぶやき・ペン、丸ゴシック=やさしい問いかけ)。筆の書体は使わない。
- 文字は全コマで縁11px以上。1コマ目はできあがりの形にする。
