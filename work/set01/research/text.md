### 8個セットならこれ(推奨8個)

全年代・全用途で使えるよう、「上位の定番」と「友だち向け/敬語の組」を入れた。

| No | セリフ | 役割 |
|---|---|---|
| 1 | OK! | 全年代1位。返事 |
| 2 | 了解です | 全年代2位前後。丁寧すぎない返事 |
| 3 | ありがとう | 友・家族向けのお礼 |
| 4 | ありがとうございます | 目上向けのお礼(3と組) |
| 5 | おつかれさまです | 30代以上で上位 |
| 6 | おはよう | 30代以上で上位のあいさつ |
| 7 | ごめんね | 謝る |
| 8 | よろしくお願いします | 30代以上で増える「おねがい」 |

- 入れ替え案(推測): 職場寄りにするなら 2「了解です」→「承知しました」。家族・カップル寄りにするなら 8 →「おやすみ」。
- 注意: 1と2はどちらも「了承」。8個しかないので、1のポーズは元気(親指・丸サイン)、2は軽いお辞儀、と見た目で差をつける(推測)。

### 2-2 文字サイズ・縁取りの目安(370×320pxで作る場合)

数字は推測(縮小表示での読みやすさから決めた制作目安)。

| 項目 | 目安 |
|---|---|
| 配置できる範囲 | 上下左右に10pxの余白を取り、内側の 350×300px に収める(10pxは解説記事の目安) |
| 2〜4文字(OK!、おはよう) | 文字の高さ 70〜90px(Canvaのフォントサイズで約70〜90) |
| 5〜9文字(了解です〜ありがとうございます) | 文字の高さ 45〜60px。2行に分けてもよい。40px未満にしない |
| 文字が占める広さ | 画面の 1/4〜1/3。キャラの顔とかぶらない位置(上か下) |
| 内側の縁取り(白) | 文字の高さの10〜12%(例: 文字の高さ70pxなら 7〜8px) |
| 外側の細い線(濃い色) | 2〜3px。白い縁取りが白いトーク背景に埋もれないようにする |
| キャラの主線 | 4〜6px の濃い色。キャラの外側にも白フチ 6〜8px |

Canvaでの作り方(推測・使う前にCanvaで確認): 文字に「エフェクト → スプライス」をかけてオフセット0・太さを最大近くにすると縁取りつきの文字になる。外側の線を足すときは、同じ文字を複製して後ろに置き、太い縁取りを濃い色でかける。「シャドウ」「ネオン」のようなぼかし・半透明のエフェクトは使わない(緑の背景がにじみ、透過したあとに緑のフチが残るため)。

## 3. 推奨配色パレット3案(HEX)

共通ルール
- 文字は濃い色+白の縁取り+外側に濃い色の細い線、の3層。白いトーク背景では濃い色の文字と外側の線が、黒いトーク背景では白い縁取りが見えるので、ライト/ダーク両方で読める。
- 緑系の色(色相がおよそ70〜170度の黄緑・緑・青緑)は、文字・縁取り・キャラ・アクセントのどれにも使わない。#00FF00 を背景にして抜くときに一緒に消えたり、フチが残ったりするのを防ぐため。
- コントラスト比は、WCAGの相対輝度の計算式で白(#FFFFFF)と比べた概算(推測計算)。
