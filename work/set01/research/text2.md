# LINEスタンプ市場調査 B-2: セリフの見せ方(字体・色・配置・アニメ・ゆるい絵柄)

- 調査日: 2026-10-22
- 担当: 市場調査B(セリフ・フォント・色)/ `research/text.md` の続き
- きっかけ(ユーザーの指摘): 今のセリフ(M PLUS Rounded 1c ExtraBold・紺・白フチ・キャラの上に横書き)は「絵とセリフが別々で一体感がない」。売れているスタンプは手書き感のある字体・色の使い分け・キャラと一体の配置がある。絵も線が硬く、流行りはもっとゆるくてフワフワしている。
- 今の set01 の状態(`preview/02.png` を見て確認): 文字は上の約45%を占める大きな紺の丸ゴシック2行、キャラは下に小さく(幅約120px/320px)離れて立っている。文字とキャラが重ならず、色もキャラの色と関係がない。輪郭線は濃いプラム茶4pxの均一な線で、形は左右対称のきれいな楕円。
- 調査方法の注意: 2026-10-22 時点でも WebFetch は全ドメインで名前解決エラー(getaddrinfo ENOTFOUND。creator.line.me / fonts.google.com / note.com で確認)となり、本文を開けなかった。情報は WebSearch の検索結果の要約・抜粋から取っている。
- 表記: **[確認]** = 検索結果で確認できたこと / **[推測]** = 確認できず、デザインの一般論や今の set01 の状態から考えたこと。

## 0. 結論(先に要点)

1. 字体: 丸ゴシックをやめ、**手書き系の1書体**にする。本命は **Yusei Magic**(油性マジックの手書き。縦線が太く横線が細いので読みやすい。OFL)。2番手は **Klee One SemiBold**(ペン字・教科書体系。敬語らしい落ち着き)。
2. 色: 文字色を紺(キャラと関係ない色)から、**キャラの輪郭線と同じ濃い茶+強調語だけキャラの補色寄りの色**の2色にする。フチは白の太フチ+外側に細い茶の線(二重フチ)。[推測]
3. 配置: 「上に文字/下にキャラ」の分割をやめ、**キャラを大きくして文字をキャラに少し重ねる・添える**。行ごとに傾け、強調語を大きく、敬語の語尾(ございます・です)を小さくする。[推測]
4. アニメ: 「よろしく」→「お願いします」の分割出しや一文字ずつのポン出しは**使ってよいが、1フレーム目は必ず完成形**(全文が見える)にする。1フレーム目がトーク画面を開いたときやショップのプレビューで静止画として使われるため。[確認]
5. 絵柄: 線を細く(4px→2.5〜3px)、色を真っ黒寄りから**明るめの茶**に、形を**少しいびつ**に(完全な左右対称・完全な楕円をやめる)、目を顔の下寄りに、色を淡く。[一部確認・数値は推測]

### 1-2 候補フォントの比較(すべて Google Fonts で配布・SIL OFL 1.1 = 商用可)

| フォント | 系統 | 特徴(根拠) | ウェイト | set01(敬語・30〜50代・インコ)との相性 |
|---|---|---|---|---|
| **Yusei Magic**(ユセイマジック) | 油性マジック手書き | 油性マジックの手書きが元。縦線が太く横線が細く視認性が高い。JIS第1・第2水準漢字を収録(「承」「解」「願」「疲」も出る)[確認] | Regular のみ | **本命**。太さがあり縮小しても読める。手書き感があるのに子どもっぽすぎない。前回 text.md の「たぬき油性マジック」と同じ作者系(tanukifont)[確認: GitHub tanukifont/YuseiMagic] |

| **Hachi Maru Pop** | 80年代丸文字 | 1970〜80年代に若い女性に人気だった丸文字。大きいサイズ向けのインフォーマルな手書き [確認] | Regular のみ | かわいいが若い・ふざけた印象で、目上向け敬語には軽すぎる [推測]。Canva にあるかは**確認できなかった** |
| **Zen Kurenaido** | ボールペン手書き | 毛筆要素を除き骨格だけ残した、ボールペンで書いたような字 [確認] | Regular のみ | 線が細すぎてスタンプの主セリフには不向き [推測] |

**Canva で使えるか(重要)**
- Canva 無料プランでは自分のフォントをアップロードできない(Pro・Teams等の機能)[確認: sungrove / trupeer 等の解説、Canva公式ヘルプのページあり]。つまり **Canva の内蔵リストにあるフォントしか使えない**。
- Yusei Magic と Zen Kurenaido は「Canva 無料プランで使える日本語フォント」として紹介している海外ブログがある [確認: rigorousthemes。ただし第三者の記事1件]。Klee One・Yomogi・Hachi Maru Pop が Canva にあるかは**確認できなかった**。
- → 制作前に Canva のフォント検索で「Yusei Magic」「Klee One」を引き、王冠マーク(Pro)がないか確認する。無ければ前回の「たぬき油性マジック」(Canva無料と紹介あり・同系統)を代わりに使う。

## 2. 色の使い方

### 2-1 分かったこと
- 文字の色・文字を囲む枠(フチ)の色の組み合わせで印象が大きく変わる [確認: AppBank]。
- 使う色の数を絞ると画面の雰囲気がまとまりやすい / 白の面積を多くすると淡い雰囲気になる [確認: clipstudio 配色記事の検索抜粋]。
- 「1つのセリフ内で色を分ける割合」「強調語に何色が多いか」「フチの太さの平均」などの統計は**確認できなかった**。以下は推測。

### 2-2 set01 への推奨 [推測]
**考え方**: 一体感は「文字の色をキャラの色から取る」ことで出す。今の紺 `#233A6B` はキャラ(黄・茶・青紫)のどこにも無い色なので、文字だけ浮いて見える。

| 役割 | HEX | 使い方 |
|---|---|---|
| 基本の文字色 | `#5B3A2E`(こげ茶) | キャラの新しい輪郭線(5章)と同じ色にそろえる。白との比 約10:1 |
| 強調語の色 | `#F0607A`(コーラルピンク)または `#FF8A3D`(オレンジ。くちばしと同系) | 1スタンプ1か所だけ。お礼・あいさつの「中身」の語(ありがとう / お疲れさま / おはよう / 承知 / 了解)に使う。セット内で強調色は1色に統一 |
| 小さい語尾の色 | 基本の文字色と同じ `#5B3A2E` | 「ございます」「です」「しました」は色を変えず、小さくするだけ |
| フチ(内側・白) | `#FFFFFF` | 太さ = 文字サイズの約14〜16%(48pxの字で7px)。今の約11%より太くして「シール感」を出す |
| フチ(外側・細線) | `#5B3A2E` | 2px。白フチの外にもう1本 = 二重フチ。白いトーク背景でも白フチの輪郭が見え、黒背景では白フチが効く |
| 色フチ案(代わり) | 文字 `#FFFFFF` + フチ `#F0607A` 6px + 外側 `#5B3A2E` 2px | 強調語だけ「白抜き文字+色フチ」にする方法。強調がよりポップになる |

- 緑系(色相 70〜170°)は引き続き禁止(`#00FF00` 抜きのため)。上の色はすべて範囲外。
- コーラル `#F0607A` は白との比が約3.4:1 と低めなので、**必ず外側の茶線(2px)をつける**。

## 3. 配置

### 3-1 分かったこと
- 2024年5月から「スタンプアレンジ機能」(大きさ・角度を変えて最大6個を重ねて1つとして送る)が始まり、吹き出しや効果線だけの「補助スタンプ」が多く出ている [確認: LINEヤフー発表、Impress Watch]。→ 吹き出しの形は利用者にもなじみがある。
- 売れているスタンプで「重ねる/添える/斜め/弧/吹き出し」がそれぞれ何割かという統計は**確認できなかった**。配置のコツを具体的に書いた記事も検索では見つからなかった。

### 3-2 set01 への推奨 [推測。数値はすべて 320×270 のコマ内座標]
**キャラと文字の分け方を「上下2分割」から「重ねる」に変える。**

| 項目 | 今 | 変更後 |
|---|---|---|
| キャラの大きさ | 幅約124 × 高さ約134(コマの約半分の高さ) | 1.4倍(幅約170 × 高さ約185)。コマの高さの約70% |
| キャラの位置 | 中央下 | 中央より少し右下(x 120〜295, y 70〜258)。左上に文字のスペースを空ける |
| 文字の位置 | 上部 x10〜310 / y10〜122 に横一列で中央揃え | 左上から斜めに流す。1行目は左上(x 14〜, y 14〜)、2行目は1行目より右に 30〜40px ずらして下げ、**キャラの頭・羽に 10〜20px かぶせる**(文字を前面) |
| 行の傾き | 0°(動きで ±3°だけ) | 1行目 −6°、2行目 −3°(右上がり)。止まっていても傾けておく |
| 文字の大小 | 2行とも48px | 強調語(1行目)54〜60px / 敬語の語尾(2行目)34〜38px。比率はおよそ 1 : 0.65 |
| 一文字ごとの変化 | なし | 強調語だけ、文字ごとに ±4° の回転と ±3px の上下ずれをつける(手書きの揺れ)。Canva で一文字ずつ別テキストにする必要があるので、重ければ省く |
| 添え物 | キラキラ・汗のみ | キャラの羽先が文字に触れる / 文字の端に小さなハート・音符・「ぺこっ」などの小さい手書き文字を添える |

- 吹き出し: 8個全部に使うと単調なので、使うなら1〜2個(例: 06「すみません」を小さな角丸の吹き出しに入れて、キャラが吹き出しの陰から顔を出す)。
- 弧(アーチ)配置: 「おはようございます」のような長いセリフはキャラの頭の上に弧を描かせると一体感が出やすい。Canva の「湾曲(カーブ)」エフェクトが API の add_text で指定できるかは**確認できなかった**。できなければ一文字ずつ置く。
- タブ画像(96×74)・メイン画像(240×240)まで縮むので、2行目を小さくしても **34px を下回らない**ようにする(前回の「40px未満にしない」を、語尾だけ 34px まで緩める)。

## 4. アニメーションでのセリフの出し方

### 4-1 LINE の仕様で確認できたこと(公式ガイドラインの検索抜粋)
| 項目 | 内容 |
|---|---|
| 1フレーム目 | トーク画面を開いたとき、非対応の環境、スタンプショップのプレビューなどで**1フレーム目が静止画として表示される**。感情が伝わるイラストを1フレーム目に入れるよう案内されている [確認] |
| 最終フレーム | 最終フレームが静止画に使われるという記載は見つからなかった。アニメーション絵文字のガイドラインには「ストーリー仕立てなら最終フレームと同じイラストを1フレーム目にも入れる」とある [確認] |
| フレーム数 | 5〜20フレーム [確認] |
| 再生時間・ループ | 1スタンプ最大4秒、ループ1〜4回、「再生秒数×ループ数」が4秒以内 [確認] |
| 同じ画像の連続 | 同じ画像が続くと1フレーム扱いになることがある。全フレームが同じ画像だとアップロード時にエラー [確認] |
| メイン画像(APNG) | 240×240。セット内で選んだスタンプと同じデザインにする必要があり、メイン用だけ1コマ目を変えるなどの編集は不可(プロモーション用ガイドラインの記載)[確認] |
| 一覧で何コマ目が出るか | 「一覧表示に何フレーム目を使う」と直接書いた記載は**確認できなかった**。上の「プレビューは1フレーム目」から、一覧も1フレーム目と考えて作るのが安全 [推測] |

### 4-2 売れている動くスタンプのセリフの出し方
- 「一文字ずつ出る」「手書きで書かれていく」「跳ねる」などがどれくらい人気かのデータは**確認できなかった**。
- 跳ねる動きのフレーム設計の一般論として「下→少し上に伸びる→着地→小さく戻る」の数フレームに分けてY座標を変える方法が紹介されている [確認: 検索要約の一般論。出典記事の明記なし]。

### 4-3 set01 での出し方の型 [推測。8コマ × 125ms = 1秒、ループ2回 = 2秒は今の企画のまま]
**鉄則: コマ1 = 完成形(全文・最終ポーズ)。コマ8 → コマ1 で自然につながるように、コマ7〜8も完成形に戻す。**

| 型 | 合うセリフ | コマ割り(1〜8) |
|---|---|---|
| A 分割出し | よろしく/お願いします、ありがとう/ございます、お疲れさま/です | 1 完成形 / 2 文字なし(キャラだけ溜め)/ 3 1行目が120%で出る / 4 1行目100% / 5 2行目が上から8px落ちて出る+キャラおじぎ / 6 2行目が4px上に弾む / 7・8 完成形 |
| B 一文字ポン | 了解です! / 承知しました(5〜6文字) | 1 完成形 / 2 文字なし / 3〜6 で1コマに1〜2文字ずつ追加(新しい文字だけ130%→次のコマで100%)/ 7 全文が110% / 8 完成形 |
| C 強調語だけ跳ねる | おはようございます / すみません | 全コマで文字は出たまま。強調語だけ y −6 → 0 → −3 → 0 と弾ませ、語尾は動かさない。文字が消えるコマが無いので一番読みやすい |
| D 手書きで書かれていく | (使わない) | 一画ずつ見せるにはマスクやストローク描画が必要で、Canva の図形+テキストでは作るのが難しい。20フレーム以内では書き終わる前に途切れやすい。**今回は使わない** |

- 文字が消えるコマ(A・Bのコマ2)は1コマ(125ms)だけにする。2コマ以上消えると、トークで再生されたときにセリフが読めない時間が長くなる。
- 8個のうち型Aを3個、型Bを2個、型Cを3個くらいに分けると、セットに変化が出る。

## 5. ゆるい・フワフワした絵柄の線の特徴

### 5-1 分かったこと
| 内容 | 根拠 |
|---|---|
| フリーハンドや鉛筆で描いたラフな線が温かみを出す。デジタルでも鉛筆風のブラシを使う | [確認] assist-all(ゆるかわイラスト記事)の検索抜粋 |
| 線は細めでラフに描き、輪郭をあえて少し崩す | [確認] 同上 |
| 頬や目元にやわらかいピンクを加えると、ゆるふわ感が上がる / ほっぺにほんのり丸を足すとかわいくなる | [確認] 同上 |
| 丸みのある形と滑らかな線。目を顔の中心より少し下に置き、口を小さな曲線にすると親しみやすい | [確認] assist-all(ゆるい犬のイラスト)の検索抜粋 |
| 主線を描かず、隣り合う色の差で境目を表す「主線なし」の描き方もある。質感のあるブラシでアナログ風のやわらかさを出す | [確認] assist-all / clipstudio の検索抜粋 |
| うさぎ・ねこ・くまなどのやわらかいキャラが安定して人気 | [確認] crowdworks 等の検索抜粋 |
| 線を茶色にする / 線の色を塗りに合わせる(色トレス)とやわらかくなる | **確認できなかった**(色トレスの手順記事はあったが「やわらかくなる」効果を述べた日本語の出典は見つからず)。一般的にはよく言われる手法 [推測] |
| 線の太さの数値(何pxが流行か) | **確認できなかった** |

### 5-2 set01 への推奨 [推測。SVG 図形で描く前提で、数値は 320×270 のコマで]
| 項目 | 今 | 変更後 |
|---|---|---|
| 線の色 | `#3A2E39`(ほぼ黒のプラム茶) | `#5B3A2E`(こげ茶。文字色と同じ)。羽・足・くちばしなど内側の細かい線は、塗りの色を濃くした色(色トレス)にする: 羽 `#C98A2B`、くちばし `#D9772A`、足 `#D97A8A` |
| 線の太さ | 体4 / 羽3 / 足2.5(キャラを1.4倍にすると実質さらに太くなる) | 1.4倍に拡大したあとで 体3 / 羽・冠羽2.5 / 足・くちばし2。「太い線でくっきり」より「細めでふんわり」 |
| 線の揺らぎ | なめらかな完全な楕円・左右対称 | 体のパスの節点を増やし(4点→8点)、各点を ±1〜2px ずらす。左右の羽は角度・形を少し変える(完全なミラーにしない)。頭のてっぺんを少し平らに・下ぶくれに |
| 線の端・つなぎ目 | 閉じた図形のみ | 丸い端(round)。冠羽などは輪郭線を1か所あえて途切れさせる案もある(Canva で開いたパスが使えれば) |
| 塗り | 黄 `#FFE066` などはっきりした色 | 少し淡く: 体 `#FFE98F`、お腹 `#FFF8E3`、羽 `#F7C766`。白い面積を増やすと淡い雰囲気になる |
| ほっぺ | 青紫 `#6F7FD8` のはっきりした楕円 | 淡いピンク `#FFB3C1` の小さな丸(ゆるふわの定番)。ちいかわ似を避けたいなら、インコらしい頬斑を淡くした `#AFB8F0` でもよい |
| 目の位置 | 顔の中ほど(y 170〜186) | 顔の中心より下へ 6〜8px。目と目の間を少し広げ、くちばしを小さく(18→14px) |
| 白フチ | 体の外側に白6px | そのまま(黒いトーク背景対策)。ただし線を細くするので白フチも 5px に |

- Canva の図形ではブラシの質感(鉛筆のかすれ)は出せないので、「細め・茶色・少しいびつ・淡い色」の4点で「ゆるさ」を出す。

## 6. set01 に取り入れるべき具体的な指示

### 字体
- セリフのフォントを **Yusei Magic** に変える(Canva で検索し、Pro マークが無いことを確認)。無ければ **Klee One SemiBold**、それも無ければ **たぬき油性マジック**。8個すべて同じ1書体にする。
- 小さい添え文字(「ぺこっ」「Z」など)も同じ書体で、サイズ 20〜24px。

### 色
- 文字の基本色を紺 `#233A6B` → こげ茶 `#5B3A2E` に変える(キャラの輪郭線と同じ色)。
- 各スタンプで強調語を1か所だけコーラル `#F0607A` にする(承知/ありがとう/お疲れさま/よろしく/了解/すみません/おはよう/おやすみ)。語尾は茶のまま小さく。
- フチは二重: 内側白 `#FFFFFF` を文字サイズの約15%(54pxで8px、36pxで5px)、外側にこげ茶 `#5B3A2E` 2px。

### 配置
- キャラを1.4倍にして右下寄り(x 120〜295 / y 70〜258)に置き、文字エリアとの境界をなくす。
- 1行目(強調語)は 54〜60px で左上、−6°。2行目(語尾)は 34〜38px で右に 30〜40px ずらし −3°、キャラの頭か羽に 10〜20px 重ねる(文字が前面)。
- 強調語は余裕があれば一文字ずつ ±4° 回転・±3px 上下にずらす。
- 吹き出しは使っても8個中1〜2個まで。

### アニメ
- コマ1とコマ7・8は必ず完成形(全文+決めポーズ)。コマ1が一覧・プレビュー・トークの静止画になる。
- セリフの出し方を3つの型に分ける: A 分割出し(02・03・04)、B 一文字ポン(01・05)、C 強調語だけ跳ねる(06・07・08)。
- 文字が消えるのは1コマ(125ms)だけ。手書きで書かれていく演出は使わない。
- 8コマ×125ms・ループ2回(2秒)、フレーム数5〜20・合計4秒以内は今のまま守る。

### 絵柄
- 輪郭線を `#3A2E39` → `#5B3A2E`、太さを拡大後で 体3 / 羽2.5 / 足・くちばし2 にする。羽・足・くちばしの線は塗りを濃くした色にする。
- 体のパスを8点にして各点を ±1〜2px ずらし、左右対称をくずす。下ぶくれに。
- 塗りを淡くする(体 `#FFE98F`、お腹 `#FFF8E3`、羽 `#F7C766`)。ほっぺは淡いピンク `#FFB3C1` か淡い青紫 `#AFB8F0`。
- 目を6〜8px下げ、くちばしを小さく。
- ぼかし・半透明は引き続き使わない。緑系の色も引き続き使わない。

### 制作前に確認すること
- Canva に Yusei Magic / Klee One があり無料で使えるか(確認できなかった)。
- Canva の add_text で文字のフチ(stroke)・カーブ(弧)が指定できるか(確認できなかった)。できなければ前回の「白文字を8方向にずらして重ねる」方法でフチを作り、弧は一文字ずつ置く。
