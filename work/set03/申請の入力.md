# set03「ひつじ年のお正月」申請の入力(上から順に)

LINE Creators Market の画面の順番に並べてあります。灰色の枠の中をそのままコピーして貼ってください。
文字数は登録画面と同じ数え方(全角は2文字)で数えてあります。貼ったあと、画面の文字数が同じか確かめてください。

---

## 1. 新規登録 → 種類

**アニメーションスタンプ** を選ぶ。

### クリエイター名
すでに登録済みの名前(English: gonbe)のまま。

### コピーライト(14/50)
```

```

### 権利(ライセンス証明書・ファイルの添付・作品が確認できるURL・その他)
**すべて空欄のまま**。ファイルも付けない(キャラも絵もすべて自作のため)。

## 3. 販売情報

| 項目 | 選ぶもの |

| 販売価格 | 選べるうちでいちばん安い価格 |
| 販売エリア | すべてのエリア |

```
イラストは図形と文字で作成しています。画像生成AIは使っていません。図形の配置と編集の作業にAIアシスタントを使用しました。
```
