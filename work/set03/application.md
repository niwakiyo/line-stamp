# 申請文 set03「ひつじ年のお正月」(アニメーションスタンプ 24個)

- 作成日: 2026-11-02
- 文字数は Python で数えた。日本語は**全角を2文字**として数えた数(LINE の登録画面と同じ数え方)。上限はタイトル40・説明文160
- 英語は1文字ずつ数え、最初と最後の文字も確かめた

## タイトル

日本語(全角2文字の数え方で33 / 40)
```
ひつじ年のお正月 年賀状とあいさつ
```

英語(32 / 40。最初の文字 Y、最後の文字 7)
```
Year of the Sheep: New Year 2027
```

## 説明文

日本語(全角2文字の数え方で141 / 160)
```
もこもこのひつじ、筆で書いていく年賀状8枚、華やかな手書きのセリフ。あけましておめでとうからあけおめ・ことよろまで、和風のお正月スタンプ24種。
```

英語(151 / 160。最初の文字 A、最後の文字 .)
```
A fluffy sheep, 8 New Year cards written with a brush, and festive greetings. 24 animated Japanese-style stickers for New Year 2027, polite and casual.
```

貼ったあと、登録画面の文字数(日本語 33/40・141/160、英語 32/40・151/160)が合っているか確かめる。

## 審査で気をつける点

- 規定: 12コマ(2秒×2回)と20コマ(4秒×1回)の2種類。24個とも 320×270・300KB以下(62〜285KB)。メイン 240×240(01 のアニメ)、タブ 96×74(ひつじだけ)
