# 申請文 set03「ひつじ年のお正月」(アニメーションスタンプ 16個)

- 作成日: 2026-11-02
- 文字数は Python で数えた。日本語は**全角を2文字**として数えた数(LINE の登録画面と同じ数え方)。上限はタイトル40・説明文160
- 英語は1文字ずつ数え、最初と最後の文字も確かめた

## タイトル

日本語(全角2文字の数え方で33 / 40)
```
ひつじ年のお正月 年賀状とあいさつ
```

英語(32 / 40。最初の文字 Y、最後の文字 7)
```
Year of the Sheep: New Year 2027
```

## 説明文

日本語(全角2文字の数え方で146 / 160)
```
もこもこのひつじと、筆で書いていく年賀状、一文字ずつ書く手書きのセリフ。あけましておめでとうから、あけおめ・ことよろまで使えるお正月スタンプ16種。
```

英語(147 / 160。最初の文字 A、最後の文字 .)
```
A fluffy sheep, New Year cards written with a brush, and handwritten greetings. 16 animated stickers for Japanese New Year 2027, polite and casual.
```

貼ったあと、登録画面の文字数(日本語 33/40・146/160、英語 32/40・147/160)が合っているか確かめる。

## 審査で気をつける点

- 規定: 12コマ(2秒×2回)と20コマ(4秒×1回)の2種類。16個とも 320×270・300KB以下(26〜218KB)。メイン 240×240(01 のアニメ)、タブ 96×74(ひつじだけ)
- 文字だけにならないよう、年賀状にはひつじ・梅・はんこ、手書きのセリフにはひつじ・鏡餅・梅・紙ふぶきを入れた
- 筆の書体 Yuji Syuku と手書きの書体 Yusei Magic はどちらも SIL OFL(商用可)
- 「令和九年」は2027年で正しい
