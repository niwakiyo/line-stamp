## 1. セットの考え方

| 項目 | 内容 |
|---|---|
| タイトル案 | ていねいインコ ひつじ年のお正月 |
| 売りの一言 | ひつじになったインコと、手書きの年賀状・手書きのセリフで、目上にも友だちにも送れるお正月スタンプ |
| 売れる期間 | 12月下旬〜1月中旬(年賀の時期に集中) |
| 構成 | 4つの種類 × 4個 = 16個 |

### 4つの種類

| 種類 | 中身 | 動き |
|---|---|---|
| A. ひつじになったインコ | インコが2027年の干支「ひつじ」に変身したキャラ。もこもこの白い毛・くるんとした角・耳。目・ほっぺ・くちばしは今までのインコと同じなので、シリーズだと分かる | これまでと同じ決まり(腕は肩が支点で最大16°など) |
| B. 年賀状 | はがき1枚。筆で、縦書きの文字を**自分で書いているように**1画ずつ書き進め、最後にひつじの絵と朱色のはんこが押される | 筆先が動いて、書いたところだけ墨が現れる |
| C. 手書きのセリフ | 大きなセリフを**一文字ずつ書いていく**。書き終わると小さな飾り(鏡餅・梅・ひつじの顔など)がぽんと出る | ペン先が動いて一文字ずつ |
| D. いろいろなお正月 | 初日の出・おみくじ・お年玉・おせちなど、お正月の場面にひつじのインコがいる | Aと同じ |

### 手書きに見せる工夫(B・C)

- 1文字を2〜3コマかけて、書き順に近い向き(縦書きなら上から下、横書きなら左から右)で少しずつ現れるようにする。書いている所に筆先(B)・ペン先(C)を描く
- 書き終わったら、文字が少し弾んで「できた!」を出す
- 1コマ目は書き終わった完成形にする(LINE の決まり。トーク一覧ではここが見える)
- コマ数: 書く場面は長くなるので、LINE の上限いっぱいの **20コマ・4秒・1回再生** にする(ほかは今までどおり12コマ・2秒×2回)
- 年賀状の筆文字には、筆で書いたような無料の書体(SIL OFL など商用で使えるもの)を使う。使えるものが見つからなければ、今の手書き風の書体で書く

### 気をつけること

- **「文字だけのスタンプ」は審査で断られることがある**(LINE の審査ガイドラインの項目。set01 の品質チェックでも確認した点)。そのため、C の手書きのセリフにも、書き終わりに必ず小さな絵(鏡餅・梅・ひつじの顔)を入れる。B の年賀状も、ひつじの絵とはんこを入れる
- 干支のひつじは、だれのものでもないので使ってよい。ほかの作品のひつじに似せない
- お寺や神社の建物・マークは描かない
- 「賀正」「迎春」は目上の人に向かないので、目上向けのものには使わない。友だち向け(あけおめ・ことよろ)は分かるように分ける
- 緑は背景と一緒に消えるので使わない(門松・松の葉は描かない)
