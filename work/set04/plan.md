# 企画書 set04「ひつじのクリスマス」(アニメーションスタンプ 24個)

- 作成日: 2026-11-04
- 守る決まり: `docs/stamp_rules.md` の全部(腕・顔・口・足、文字を一直線にしない、文字だけにしない、説明文160文字、メイン画像は文字入りで華やかに、など)
- **この企画書はユーザーの承認待ち。承認されるまで作らない。**

## 1. 考え方

| 項目 | 内容 |
|---|---|
| キャラ | set03 で仕上げた**ひつじ**をそのまま使う(形・角・前髪・耳・足は直さない)。サンタ帽やトナカイの角のカチューシャを着ける |
| 理由 | 新しい動物を一から作ると、形の直しが何度も入って使用量がかかる。仕上がっているひつじを使えば、見た目の直しが出にくい |
| 色 | 赤 `#D93A3A`・こい緑 `#2E6F5E`・金 `#E8B33A`・白。背景の緑(#00FF00)と間違えて消えない、青みのある深い緑を使う |
| 文字 | カーブ・段差・大きさ違い・書体まぜ(英語は筆記体風、日本語は手書き)。一直線に並べない |
| メイン画像 | 「Merry Christmas」の文字+サンタ帽のひつじ+ツリー+雪。ひと目でクリスマスと分かる、華やかなもの |

- カードは四角い紙(角を丸くしない)。ペンは、向きは保ったまま止まる位置をランダムに

## 3. 確認のしかた(使用量を抑える)

- まず **01(サンタ)と21(カード)の2個だけ** 試作してお見せする。見た目が決まってから残りを作る
- 見せる前に、決まりごと7章の確認(全コマ・50%縮小・白と水色の背景)をする
- 確認用は1つずつのファイルで送る(zip にしない)

## 4. 日程

クリスマスは12月上旬から使われるので、**11月中旬の申請**をめざす(審査日数は不明)。
