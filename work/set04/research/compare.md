# 人気のクリスマスのサンタ・トナカイと、試作のちがい(2026-11-05)

調べた所(WebSearch の要約。数値の根拠はない):
- かわいいサンタ・トナカイは「丸いシルエット」「大きな目と大きな鼻」「ゆるいデフォルメ」「やさしい表情」が多い
- サンタは、ふっくら丸い体、帽子は丸く頭の上にのび、先にカール。ひげはほっぺから下へ波打ち、おなかまで覆う。ほっぺと鼻は赤みのある色
- トナカイは、大きな鼻とつぶらな瞳。足は短く少し曲げ、ひづめは丸くぽっちゃり
- 出典: https://lifestyle.assist-all.co.jp/?p=57888 / https://lifestyle.assist-all.co.jp/?p=54109 / https://new.nimss.org/article/how-to-draw-cute-reindeer-the-art-of-charm-in-every-line / https://data.mbrp.com/?p=16558

## 試作の悪いところ → 直し方

| 試作 | なぜ悪いか | 直し方 |
|---|---|---|
| サンタの帽子のふちが高く、ふちと目の間にはだ色が広い | 「はげ」に見える。人気のサンタは、帽子が頭全体を覆い、ふちは眉の高さ | ふちを眉の高さまで下げ、帽子を顔より広く丸く |
| サンタの横に髪がない | 頭の横がはだ色でつるつる | 帽子のふちの下から、ほっぺの横を通ってひげにつながる白い髪(もこもこ) |
| ひげが小さい | サンタらしさが弱い | ほっぺから胸まで覆う、大きなもこもこのひげ |
| トナカイの頭のてっぺんがつるつる | 「はげ」に見える | 頭のてっぺんにこい茶の毛のかたまり(前髪)。角の根元は前髪にかくす |
| トナカイの角が大きく、こい茶で枝のよう | 「頭から木が生えている」ように見える | 角は明るいベージュで小さめ、枝先を丸く。前髪の両わきから |
| クリスマスの物がツリーだけ | クリスマスのイメージが弱い | ヒイラギ(緑の葉と赤い実)をトナカイの頭や文字に、サンタは白い大きな袋をかつぐ |
| キャラがその場から動かない | 動きがさびしい | サンタは左から歩いて入ってきて手をふる。トナカイは右から走ってきて止まり、ジャンプ |
