## 6. 審査で気をつける点

| 点 | 対策 |
|---|---|
| 規定 | 16個とも 320×270・12コマ・2秒×2回・300KB以下(94〜165KB)。メイン 240×240(アニメ・109KB)、タブ 96×74 |
| 誤字 | 16個のセリフを企画書と照らし合わせ済み。「どうぞご自愛ください」「旧年中は」など、敬語と縁起の言葉も確認済み |
| ほかのキャラに似ていないか | set01 と同じオリジナルのインコ。干支のひつじは07のフードだけで、だれの作品にも似せていない |
| 宗教の表現 | クリスマスはサンタ帽とベルだけ。お正月は水引・扇・だるま・おみくじで、寺社の建物やマークは描いていない |
| AI の使用 | 絵は画像生成AIを使わず、図形とフォント(Yusei Magic)で描いた。作業には AI アシスタントを使った。申告の欄は set01 と同じ答え方にする(`../set01/sales_info.md`) |
| 申請後は直せない | 登録画面のプレビューで16個とメイン・タブを見てからリクエストする |
